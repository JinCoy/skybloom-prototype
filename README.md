# Skybloom prototype

A playable web prototype of Skybloom, a Frutiger Aero sky-garden merge puzzle. Hosted on GitHub Pages so it can be tested on phones (tilt sensors need https).

- Play: https://jincoy.github.io/skybloom-prototype/
- Demo boards: add `#sunset`, `#night` or `#lv17` to the address, then press Play.
- Tilt: Settings → Tilt Effects (iOS asks for motion access when you switch it on).

This is a test build, not a released game.
